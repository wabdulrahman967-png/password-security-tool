# 🔐 Password Security Suite v2.0

A comprehensive password security analysis tool with modern GUI, breach detection, and encryption utilities.

## ✨ Features
- Password Strength Analysis with 8 criteria
- Breach Detection using Have I Been Pwned API
- Caesar Cipher Encryption with Brute Force
- Report Generation (TXT/JSON)
- Dark/Light Theme
- History Tracking

## 🚀 Installation

```bash
# Clone repository
git clone https://github.com/yourusername/password-security-tool.git
cd password-security-tool

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Linux/Mac
# OR
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt

# Run application
python main.py
